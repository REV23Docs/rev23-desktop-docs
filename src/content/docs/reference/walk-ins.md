## Actions

**Start Service:** Creates one Service record using the information from the selected queue item.

**Start Services:** Opens the [Service Group](/rev23-desktop-docs/concepts/service-groups/) workflow for a queue item with one or more Additional Service Types. Each requested service type becomes an individual Service record, and the queue item changes to **Started** after completion.
